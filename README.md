# HNG13-Data_Analysis
A collection of all data analysis projects i worked on during HNG 13 cohort
This repository contains projects completed during my HNG Data Analytics Internship, showcasing practical applications of data cleaning, exploratory analysis, SQL querying, geospatial analysis, Python feature engineering, and dashboard development using Excel and Power BI.

The projects demonstrate my ability to transform raw data into meaningful business insights through structured analysis and visualization.

# Projects Overview

During my HNG Data Analytics Internship, I worked on real-world data projects covering:

- Retail Sales Analysis (Excel): Cleaned data, performed descriptive analysis, and identified sales trends.

- Feature Engineering & EDA: Created new variables and explored datasets to uncover insights.

- SQL Business Analysis (HNG Ride): Queried and cleaned ride data to generate business insights.

- Election Data Outlier Detection: Applied geospatial analysis and anomaly detection for data integrity.

- International Football Dashboard (Python – Team Project): Engineered features and prepared data for an interactive dashboard.

- SEO Analytics (Power BI): Analyzed keyword performance in Nigerian consumer banking.

- Palm Oil Profitability Analysis (Power BI): Researched and visualized profitability trends across Nigerian states.
